# WGS Extract  (WGSE.bio)
is a desktop tool for verifying, analyzing and manipulating your **Personal [30x WGS](https://h600.org/wiki/WGS) test** result. It can also be used with any human genome based [BAM or CRAM](https://h600.org/wiki/Sequencing+File+Formats) file including [WES](https://h600.org/wiki/WES) and Y-only test results. It is often used to extract a [microarray test file](https://h600.org/wiki/microarray%2bfile%2bformats) from [30x WGS](https://h600.org/wiki/WGS) results for analysis by other tools.

# About
This tool is geared toward the needs of [genetic genealogy](https://h600.org/wiki/Genetic+Genealogy) and [Ancient DNA](https://h600.org/wiki/Deep+Ancestry) (aDNA) studies but can be helpful for those looking into health-related uses of [WGS](https://h600.org/wiki/WGS) tests. The **personal, sub-$500, Direct-to-Consumer (DTC), 30x Whole Genome Sequence ([WGS](https://h600.org/wiki/WGS)) tests** are delivered with basic data files and reports. This tool serves to bridge the gap between the [WGS data files](https://h600.org/wiki/Sequencing+File+Formats) delivered and the present day [genetic genealogy community tools](https://h600.org/wiki/Third+Party+Analysis+Tools). 

We specifically do not do post-VCF analysis for health. But there are [other sites](https://bit.ly/DNA_Test_Interpretation) that do (google doc). Most health analysis sites accept the microarray and VCF files generated by this tool.

[Ancient DNA](https://h600.org/wiki/Deep%2BAncestry) or recent samples from research studies (e.g. [1K Genome](https://www.internationalgenome.org/data/)) are often processed with this tool.

>Still waiting for your [WGS](https://h600.org/wiki/WGS) test results?  Want to get started today?  See the [International Genome Sample Resource (1K Genome archive)](https://www.internationalgenome.org/data) for [BAM or CRAM](https://h600.org/wiki/Sequencing+File+Formats) files that you can download and play with to learn the tool while waiting for your results.

Note: while the tool processes [low-coverage sequencing](https://wiki.h600.org/Low+Coverage+Sequencing) files available from some [genetic genealogy](https://h600.org/wiki/Microarray%2BTest%2BCompanies) vendors, it does not yet have the mathematical modeling (e.g. [imputation](https://wiki.h600.org/Imputation) and bias correction) to truly make them useful.

This tool is designed to be a simple, push-button manipulation of [WGS files](https://h600.org/wiki/Sequencing+File+Formats) from any source. It hides the installation and scripting of complex bioinformatic tools and automatically adapts based on the data within your files.  For more control over your pipeline, either learn to use the underlying tools or seek out a Galaxy server (such as [UseGalaxy](https://usegalaxy.org/)). As of 2026, the [Forensic Genetic Genealogy market](https://doi.org/10.1016/j.fsigen.2025.103387) has developed their own, similar tool for use in law enforcement settings. But it uses imputation and starts from [FASTQ/BCL](https://h600.org/wiki/FASTQ) files only.

[Dante Labs](https://genome.dantelabs.com), [Nebula Genomics](https://nebula.org/), [Nucleus Genomics](https://mynucleus.com/), [Sequencing](https://sequencing.com/), [tellmeGen](https://tellmeGen.com/), and [YSEQ](https://yseq.net/) are test results most commonly used with this tool. [Full Genomes Corp](https://fullgenomes.com/]), [GeneDX](https://www.genedx.com/), [Sano Genetics](https://sanogenetics.com), [Invitae](https://www.invitae.com/) and [Veritas (historical)](https://veritasgenetics.com) are other test providers whose output is processed here. These are all results from [Illumina](https://illumina.com) and [MGI](https://en.mgi-tech.com/) / [Complete Genomics](https://www.completegenomics.com/) next generation sequencers ([NGS](https://h600.org/wiki/ngs)).  Results from [Oxford Nanopore](https://nanoporetech.com/) and [PacBio HiFi CCS](https://www.pacb.com/smrt-science/smrt-sequencing/hifi-reads-for-highly-accurate-long-read-sequencing/) third generation, long-read sequencers can often also be used; as can [FamilyTreeDNA](https://familytreedna.com/)'s BigY output. [MyHeritage](https://myheritage.com/) new low-coverage [WGS](https://h600.org/wiki/WGS) [CRAM](https://h600.org/wiki/Sequencing+File+Formats) replacing their [microarray](https://h600.org/wiki/microarray) test and their future DNA360 [30x WGS](https://h600.org/wiki/WGS) files work here.  [MyHeritage](https://myheritage.com/) are processed on an [Ultima Genomics](https://www.ultimagenomics.com/) sequencer which requires a modified pipeline which we have now included. The [FamilyTreeDNA](https://familytreedna.com/) new Family Finder Twist Biosciences enrichment [NGS](https://h600.org/wiki/NS) result [CRAM](https://h600.org/wiki/Sequencing+File+Formats) (if and when they provide it) should be processable here also. (This is not an endorsement of any company or service; simply reporting what is commonly used with the tool.)

# Supported Platforms v6
* **v6** is meant to be a native, signed installer for all current Microsoft Windows, Apple MacOS and Linux platforms on 64 bit Intel/AMD, ARM 64, and Apple M* CPU's. It has also been optimized to take advantage of GPU's when available (optional enabling). Care has been taken to make the tools useable on a wide performance range of systems.  But bioinformatics is often demanding. Requiring a minimum of 16 GB of main memory and 300 GB of free disk space during some operations.

# Supported Platforms pre-v6
* **v6** is meant to be a native, signed installer for all current Microsoft Windows, Apple MacOS and Linux platforms.
**64 bit OS and processor platforms** tested as part of the release process are:
* **Microsoft Windows 10 and 11 on Intel and AMD 64 bit processors** using either **Cygwin64** or **Msys2** for the bioinformatic tools (you choose).  
(note: WSLG in Win11 with a Linux Desktop (not server) can be used to install the Ubuntu or Linux release of this tool.)
* **Apple MacOS 15 (Sequoia) through 27 (Golden Gate) on Intel and Apple Mx processors** using either **Macports** or **Homebrew** for the bioinformatic tools (you choose).

(note: 18.04 is deprecated due to dropped support for needed tool ports.)
* **Any Linux by using Conda** (actually micromamba and bioconda) on **Intel, AMD or Arm** processors. This will soon deprecate the Ubuntu installer.

# Installation Notes (pre v6)
The ZIP archives linked above are just the installer scripts.  You need to download, unpack and run the installer script for your OS. See the **Installation Section** in the [v4 user manual](https://get.wgse.io/WGSExtract_v4_User_Manual) for specific details about installing on your platform.  See the **v4 Release Notes** in the installation directory for more information about the updates in the current release. You should periodically re-run the installer to update to the latest release in the track you select. There is information available on how to use [hashes to verify the Installer you download](https://www.howtogeek.com/67241/htg-explains-what-are-md5-sha-1-hashes-and-how-do-i-check-them/).

>* Starting with **MacOS Sequoia 15.0**, Apple has permanently removed the option to allow for non-signed installs. The only way to run non-app-store and non-apple "notarized" apps is, within 30 minutes of downloading and trying to open the first time (and clicking **Done** in the pop-up that comes when you try to run it), you must navigate to **systems settings** / **privacy & security** and scroll all the way down to the **Security** section.  You should see **"Install_macos.command" was blocked to protect your Mac.** with a button next to it that says "Open Anyway". Once clicked there, you will then get the old "open anyway" pop-up to finally approve the program. You will also be required to enter your password in a follow-on pop-up to approve the action.  You must do this each time you download and install an update as well.

# Windows Release Users (pre v6)
Some have downloaded the **WGS Extract** tool solely to gain access to the MS Windows native executables of the Bioinformatic Tools.  You can use these Bioinformatic tools independent of the **WGS Extract** program.  Look in the cygwin64/usr/local folder for the bioinformatic tools. Just add cygwin64/bin and cygwin64/usr/local/bin to your PATH to make the programs available from the Terminal command line of CMD, Powershell or BASH. If you do not wish to use the rest of the **WGSE** release, just delete everything except the cygwin64 folder and adjust your path for wherever you move the folder. For those using the new Msys2 release, it is the msys2/usr/bin and msys2/ucrt64/bin folders; respectively.

Since v4, this is a full, BASE environment of Cygwin64 that is captured as of the stated release date.  The bioinformatic tools are compiled to this same version on that release date. So do not update the cygwin64 libraries else the bioinformatic tools will break. Msys2 is just a minimal set of tools to operate **WGSE**.
