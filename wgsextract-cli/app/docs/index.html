WGS Extract Desktop App — User Documentation

Welcome to the user documentation for the WGS Extract desktop app (the graphical front-end built on top of WGS Extract CLI).

Web version: These guides are also published as rendered HTML at wgse.bio/wgsextract-cli/app/docs/ (CLI documentation is at wgse.bio/wgsextract-cli/docs/).

Core guides#

GuideWhat it covers
Basic and Advanced modeSwitching between Basic and Advanced mode, how hidden controls behave, and output folder defaults
Reference DataInstalling, verifying, and removing annotation databases, Gene Maps, liftover chains, VEP caches, and research panels
Reference GenomesInstalling, indexing, verifying, and deleting reference genomes; cached vs. looked-up download sizes
ToolsViewing mandatory and optional bioinformatics tools, installing/uninstalling Pixi-managed tools, and manual tool notes
SettingsSetup, appearance & language, bug reporting, workspace folders (config.toml), and moving libraries to another drive
Privacy and network accessWhat stays local, automatic update checks, interactive download prompts, IP/metadata visibility, and how to run completely offline

GuideWhat it covers
Built-in genome viewerInspecting local BAM/CRAM alignments, VCF variants, RefSeq genes, and optional remote server viewing
Gene pageViewing one gene's RefSeq transcripts, exon coverage, and annotated variants offline

Analysis page guides (coming soon)#

Detailed guides for the analysis and workflow pages (FASTQ, BAM, VCF, Extract, Microarray, Ancestry, Annotate, and Workflow) will be added once the upcoming analysis-page restructure is finished. Until then:

  • Hover over any button, field, or table row in the app to see its built-in tooltip.
  • For the underlying bioinformatics behavior, flags, and file formats, see the WGS Extract CLI documentation.
