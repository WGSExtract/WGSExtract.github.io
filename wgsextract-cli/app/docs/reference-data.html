Reference Data

The Reference Data page (near the bottom of the sidebar) manages the shared annotation databases, coordinate maps, liftover chains, microarray templates, and research panels used by WGS Extract workflows, the Genome Viewer, and the Gene Page.

Reference genomes (FASTA sequences and aligner indexes) live on their own Reference Genomes page.

Reference Data Library folder#

The Reference Data Library path at the top of the page shows where these datasets are stored (by default inside your users workspace, ~/wgs-extract). It shows the resolved absolute path without changing your saved setting.

  • You can point this folder to another location, such as a larger external SSD.
  • When you change the folder path, the app offers three choices:
    • Move: Copies existing reference data to the new folder and updates config.toml.
    • Change Setting Only: Updates config.toml to use the new folder without moving or deleting existing files.
    • Cancel: Leaves the path unchanged.
  • This works in both Basic and Advanced mode.

Installed and available datasets#

The table queries wgsextract ref status locally — opening the page does not contact the network. Each row shows its status (Installed or Missing), version, target genome build, what it is used for, and either its on-disk size (when installed) or approximate download size (when missing). Hover over a row to see its data source, publishing organization, and license summary.

Library Bootstrap always shows the current archive's download size. If the installed version differs, the versions are listed as installed / available. An older installation is marked Update available.

Row actions#

  • Install / Download: Runs the corresponding wgsextract ref ... or wgsextract vep download command and streams progress to the terminal pane. Larger downloads ask for confirmation first.
  • Verify: Checks integrity of an installed resource (for example, the Ensembl VEP cache).
  • Delete: Asks for confirmation before removing an installed dataset from disk to free space.

Interactive prompts: If you start an analysis or open the Gene Page without a required dataset (such as Gene Map), WGS Extract lets you Install and Continue directly from the prompt instead of switching to this page first. See Privacy and network access for what each download sends.

Advanced mode options#

Switching to Advanced mode reveals extra controls below the table:

  • Annotation build (hg38 / hg19) for CADD, GERP++, and PhyloP downloads.
  • gnomAD release (2.1.1 / 4.1).
  • yBrowse snapshot file path, to install from a local snapshot instead of fetching online.
  • VEP species, VEP version, VEP mirror (ebi / uk), and VEP assembly (GRCh37 / GRCh38).
  • Custom download section: Download an arbitrary public reference file from a URL to a chosen local path (wgsextract ref download).
