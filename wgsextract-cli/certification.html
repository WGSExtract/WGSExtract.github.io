Reference

Command certification

See what each command has been checked against, on which platforms, and where the evidence stops.

What the levels mean

  • Certified: Real-data truth or upstream parity on Linux, macOS and Windows, real-tool regression tests, and production use without open correctness bugs.
  • Validated: Real-data validation on at least one platform, real-tool tests and documented limits.
  • Tested: Fixture or fake-genome tests exercise the real tools or built-in operation.
  • Experimental: Coverage is partial or unverified, or the command is research-only. Use with care.

A level applies to the evidence listed, not to every input, option or backend. Research features can remain Experimental even when their mechanics have been tested. Platform entries describe the linked qualification; a missing entry is not an unsupported-platform claim.

Running a Tested or Experimental operation logs a notice; asking for help does not run the operation. Set certification_notices = false in config.toml to hide it without changing the level recorded in results. The notice is not a run warning.
