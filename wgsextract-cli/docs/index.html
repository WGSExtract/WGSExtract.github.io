WGS Extract CLI documentation

Scope: This docs/ folder documents WGS Extract CLI — the command-line back-end, Python API and local server.

Looking for the desktop app (GUI front-end)? See the desktop app user guides (rendered web docs) or the desktop app developer docs.

Start with the README quick start, the CLI documentation site, or wgsextract help --all. This index lists every top-level CLI guide; the command reference, API and configuration reference are generated from their sources.
