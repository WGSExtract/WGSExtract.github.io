WGS Extract CLI (wgsextract-cli)

An independent command-line recreation of WGS Extract. Inspect BAM/CRAM files, simulate consumer microarray files, extract Y/mtDNA, call and annotate variants, and manage reference genomes from the terminal. It wraps samtools, bcftools, bwa/minimap2, GATK, Haplogrep, VEP and other tools, with native Yleaf-derived Y-DNA analysis. Pixi provides Python and bioinformatics tools on macOS, Linux and Windows.

  • Desktop app, which bundles this CLI; installers ship with each release. See the app site.

Privacy#

Default commands stay offline: no telemetry, background update checks or silent reference downloads. Missing public data requires an explicit --download; sample-derived information must never be sent without a separate, documented opt-in. See network permissions and destinations.

Install#

On macOS or Linux, open Terminal and run:

curl -fsSL https://raw.githubusercontent.com/WGSExtract/wgsextract-cli/main/install.sh | sh

The script comes from main but installs the latest published release into ./wgsextract-cli/, not the development branch. On macOS it checks for Xcode Command Line Tools. Linux x86_64 and native ARM64 use the same installer; see Linux ARM64 support and limitations.

On Windows, clone or download this repository, then run in PowerShell:

.\install_windows.bat

This installs Pixi when missing and native Windows tools; no WSL or MSYS2 is needed. See the Windows guide.

Installer options and uninstall details cover pinned versions, custom directories, verification and preserved data. The site install guide also walks through platform setup and the reference library.

Examples below write plain wgsextract; substitute your launcher. Optional tools must be installed explicitly before use. Feature commands check dependencies; they never install them.

Uninstall#

./wgsextract-cli/uninstall.sh --yes

This removes the installation, including reference data inside it. Back up anything you want to keep first. Configuration and user-level Pixi are kept unless you request --remove-config or --remove-pixi. For Windows and custom locations, see the uninstall guide.

Quick start#

Use your own BAM/CRAM in place of sample.cram. Install the exact reference it was aligned to: hs38 below is an example, not interchangeable with every GRCh38 reference.

# Explicit downloads: library metadata, then a matching reference genome
wgsextract ref bootstrap
wgsextract ref library --list
wgsextract ref library --install hs38

# Validate installed tools (exit 3 if a mandatory tool is missing)
wgsextract deps check

# Inspect the alignment and its reference build
wgsextract info --input sample.cram --detailed

# Simulate a 23andMe v5 raw-data file
wgsextract microarray --input sample.cram --formats 23andme_v5

# Extract mitochondrial variants and predict the maternal haplogroup
wgsextract extract mito-vcf --input sample.cram
wgsextract lineage mt-haplogroup --input sample.cram --download

--download explicitly allows the first-use public haplogroup tree download, which ref bootstrap does not include. Omit it for offline use once cached; no sample data is uploaded.

Try a small region (--region chrM, where supported) before a whole genome: large jobs can take hours and hundreds of gigabytes of working space. See resource estimates before starting.

Find the next command with wgsextract help --all or the command reference. For scripts and agents, use wgsextract help --all --json for the compact index, then wgsextract help <command> --json for required arguments, options, examples and typed input schemas. Key flags in the index are hints, not complete invocations.

Commands exit non-zero on failure. Writers record inputs, outputs, warnings and provenance in a result manifest; --json prints structured results while logs stay on stderr. See running commands for option placement, progress and logging.

Reporting a problem#

Run wgsextract report-issue --last-failed to prepare a locally redacted report, or wgsextract report-issue --print to inspect the last run without opening a browser. Nothing is uploaded automatically: review before submitting. See report contents, privacy and options, or open an issue.
