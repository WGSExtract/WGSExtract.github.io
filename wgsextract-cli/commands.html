Reference

Command reference

Browse the full CLI by tier or start with the files you have.

Commands are grouped by tier. The core tier is the usual path, in order: check a file, make microarray files or find haplogroups, extract reads, (re)align, call and annotate variants, then summarise them in a report. Outputs go to the output directory (--outdir, the configured outdir or the --genome folder) unless noted; a run that registers outputs also writes a .manifest.json beside its main output. Run wgsextract help <command> for its options (--help-all adds the advanced ones). Agents: start with wgsextract help --all --json for a compact index, then wgsextract help <command> --json for options and schemas; wgsextract help --all --json --full dumps everything. Needs lists the external tools a command checks for (wgsextract deps check shows which are installed) and how long it typically takes.

Start from what you have

  • Nothing yet (a first run): deps check (check that the external tools are installed) → ref bootstrap (download the small shared files, e.g. liftover chains) → ref library (download a reference genome) → example-genome download (get a public example genome to practise on)
  • A BAM or CRAM from a sequencing service (Nebula, Dante Labs, Sequencing.com, ...): info (check the reference build, file health and coverage) → microarray (make 23andMe/AncestryDNA-style files to upload) → lineage y-haplogroup (find the paternal haplogroup) → lineage mt-haplogroup (find the maternal haplogroup) → vcf snp (call SNPs into a VCF) → vep run (predict each variant's effect on genes) → report (summarise everything in one HTML report)
  • A BAM or CRAM on the wrong build (hg19 when you want hg38, or the reverse): info (see which build it is) → realign (re-map it to the other build) → info (check the new file, then continue as above)
  • FASTQ files (raw reads): align (map the reads to a reference, making a BAM/CRAM) → info (check the result, then continue as for a BAM/CRAM)
  • A VCF (from a provider or another pipeline): vcf prepare (fix its compression, sorting, contig names and index) → vcf clinvar (add ClinVar clinical significance) → vcf filter (keep a gene, region or quality range) → vep run (predict each variant's effect on genes) → vcf table (one row per variant, for spreadsheets and SQL)
  • A consumer raw-data file (23andMe, AncestryDNA, ...): info chip (identify the vendor, chip and revision)

Start here, in this order

Command What it does Writes Needs Example
info Check a BAM/CRAM: reference build, file health, coverage. Prints a summary and caches it as <input file name>.wgse_info.json; with --format also <input file name>_chromosomes and _qc (QC stats) as .tsv or .parquet. samtools; depending on options and inputs, also: bcftools; seconds on a 30x genome wgsextract info --input sample.cram
info calculate-coverage Generate a full breadth-of-coverage report. <input file name>_coverage.tsv, or with --bins <input file name>coverage_bins.tsv (depth bands, or .parquet with --format parquet) instead; with --with-bins both .tsv files. With --by, <input><bed>target_coverage.tsv (depth per target) and <input><bed>_target_summary.txt (on- and off-target depth, enrichment and targets below --min-depth). --status writes nothing. samtools; depending on options and inputs, also: bcftools; minutes on a 30x genome wgsextract info calculate-coverage --input sample.cram
info coverage-sample Quickly estimate per-chromosome breadth of coverage by sampling ~1,000 evenly spaced, length-weighted 1 kb windows. <input file name>_samplecvg.json; a whole-file run also updates the info cache. samtools; depending on options and inputs, also: bcftools; minutes on a 30x genome wgsextract info coverage-sample --input sample.cram
info gene Look at one gene from local data: its span and RefSeq transcripts, your VCF's variants in it with consequence, ClinVar, gnomAD and research-only ACMG annotations, and BAM/CRAM read depth over each exon against a callable threshold. Prints the gene's span, transcripts, variant counts and exon coverage; --json has the full wgsextract.gene/1 document in details. With --export, <vcf stem><gene><filter>_variants.tsv. samtools; depending on options and inputs, also: bcftools, tabix; seconds for a gene wgsextract info gene --gene BRCA1 --input sample.cram --vcf-input sample_annotated.vcf.gz
info chip Identify the vendor, chip and revision of a consumer microarray raw-data file (23andMe, AncestryDNA, MyHeritage, FTDNA, ...) from its header and marker set, with a confidence score and the matching --formats template. Prints the vendor, chip and matching --formats template; writes no files. no external tools; seconds for a raw-data file wgsextract info chip --input genome_raw_data.txt
microarray Make 23andMe/AncestryDNA-style raw-data files to upload. <input stem>_<format>.txt (or the vendor's extension) per format, such as sample_23andMe_V5.txt, and <input stem>_CombinedKit.txt; with --format also <input stem>_genotypes.tsv or .parquet. Each output gets an <output>.inputs.json of the inputs and options that made it; a rerun reuses outputs whose inputs are unchanged. bcftools, bgzip, samtools, tabix; depending on options and inputs, also: curl; minutes on a 30x genome wgsextract microarray --input sample.cram --formats 23andme_v5
lineage y-haplogroup Predict paternal haplogroups with native Yleaf-derived analysis (BAM/CRAM/VCF). yleaf/: hg_prediction.hg, the per-sample .out/.fmf/.info reports and run.json; prints the haplogroup and the tree's name and version. bcftools, samtools; minutes on a 30x genome wgsextract lineage y-haplogroup --input sample.cram
lineage y-str Count Y-STR repeats (FamilyTreeDNA Y-12 to Y-111, PowerPlex Y23, Yfiler Plus) from a BAM/CRAM for genealogy matching. ystr/: <sample>.ystr.tsv, <sample>.ftdna.csv (FTDNA marker order) and run.json. samtools; depending on options and inputs, also: bcftools; minutes on a 30x genome wgsextract lineage y-str --input sample.cram --panel Y-37
lineage mt-haplogroup Predict your maternal haplogroup using Haplogrep 3, optionally checking mtDNA contamination with haplocheck. haplogrep_results.txt; prints the mtDNA haplogroup and Haplogrep 3 tree. With --contamination, also haplocheck_contamination.txt (+ .raw.txt, .html). bcftools, haplogrep3, java, samtools; depending on options and inputs, also: curl, haplocheck, tabix; minutes on a 30x genome wgsextract lineage mt-haplogroup --input sample.cram
extract mito-fasta Extract the Mitochondrial DNA (chrM) consensus sequence. <input stem>_MT.fasta: the mtDNA consensus sequence. bcftools, samtools, tabix; depending on options and inputs, also: sambamba; minutes on a 30x genome wgsextract extract mito-fasta --input sample.cram
extract mito-vcf Call variants specifically for the mitochondrial DNA. <input stem>_MT.vcf.gz (+ .tbi). bcftools, samtools, tabix; depending on options and inputs, also: sambamba; minutes on a 30x genome wgsextract extract mito-vcf --input sample.cram
extract mt-bam Isolate all mitochondrial-related reads into a new, smaller BAM file. <input stem>_mtDNA.bam (+ .bai). samtools; depending on options and inputs, also: bcftools, sambamba; minutes on a 30x genome wgsextract extract mt-bam --input sample.cram
extract ydna-bam Extract all Y-chromosome reads into a separate BAM file. <input stem>_Y.bam (+ .bai). samtools; depending on options and inputs, also: bcftools, sambamba; minutes on a 30x genome wgsextract extract ydna-bam --input sample.cram
extract ydna-vcf Call variants specifically for the Y-chromosome. <input stem>_Y.vcf.gz (+ .tbi). bcftools, bgzip, samtools, tabix; depending on options and inputs, also: sambamba; minutes on a 30x genome wgsextract extract ydna-vcf --input sample.cram
extract y-mt-extract Extract both Y-chromosome and Mitochondrial reads into a single, combined BAM file. <input stem>_Y_MT.bam (+ .bai). samtools; depending on options and inputs, also: bcftools, sambamba; minutes on a 30x genome wgsextract extract y-mt-extract --input sample.cram
extract unmapped Extract reads that did not align to the reference. <input stem>_unmapped.bam (+ .bai); FASTQ files with --fastq. samtools; depending on options and inputs, also: bcftools; minutes on a 30x genome wgsextract extract unmapped --input sample.cram
extract custom Extract reads from a specific chromosomal region or gene of interest. <input stem>_<region>.bam (+ .bai). samtools; depending on options and inputs, also: bcftools, sambamba; minutes on a 30x genome wgsextract extract custom --input sample.cram --region chr17:43044295-43125483
extract region Extract the mtDNA, the Y chromosome, both, or the autosomes and X chromosome as any of a BAM, a VCF and a consensus FASTA. Per chosen format: <input stem>_mtDNA|Y|Y_MT|autosomes_X.bam (+ .bai), <input stem>_MT|Y|Y_MT|autosomes_X.vcf.gz (+ .tbi) and .fasta. samtools; depending on options and inputs, also: bcftools, bgzip, tabix; hours on a 30x genome wgsextract extract region --input sample.cram --target ymt --formats bam,vcf
realign Re-map a BAM/CRAM to another build, e.g. hg19 to hg38. <input stem>_aligned.bam or .cram (+ index); with --keep-fastq, also <input stem>_R1/_R2.fastq.gz (single-end ONT/PacBio: <input stem>.fastq.gz). Completed steps are recorded in <output>.steps.json, so a rerun resumes after a crash. samtools; depending on options and inputs, also: bcftools, bgzip, bwa, bwa-mem2, bwa-mem3, curl, gatk, minimap2, pbmm2, sambamba, samblaster; hours on a 30x genome wgsextract realign --input sample_hg19.bam --ref hs38.fa
align Map raw FASTQ reads to a reference, making a BAM/CRAM. <reads stem>_aligned.bam or .cram (+ index). samtools; depending on options and inputs, also: bcftools, bwa, bwa-mem2, bwa-mem3, curl, gatk, minimap2, pbmm2, sambamba, samblaster; hours on a 30x genome wgsextract align --r1 sample_R1.fastq.gz --r2 sample_R2.fastq.gz --ref hs38.fa
vcf snp Call Single Nucleotide Polymorphisms (SNPs) using bcftools. snps.vcf.gz (+ .tbi); with --reference-evidence gvcf also bcftools.g.vcf.gz (+ .tbi). bcftools, samtools, tabix; hours on a 30x genome wgsextract vcf snp --input sample.cram
vcf indel Call Small Insertions and Deletions (InDels) using bcftools. indels.vcf.gz (+ .tbi); with --reference-evidence gvcf also bcftools.g.vcf.gz (+ .tbi). bcftools, samtools, tabix; hours on a 30x genome wgsextract vcf indel --input sample.cram
vcf call Call several variant types in one run: SNPs and InDels (bcftools), SVs and CNVs, each into its own VCF, and with --merge also into one combined VCF. Each type's own VCF (snps.vcf.gz, indels.vcf.gz, the SV caller's VCF, cnv.vcf.gz), with --reference-evidence gvcf one bcftools.g.vcf.gz for SNPs and indels instead; --merge replaces them with variants.vcf.gz (variants.g.vcf.gz with the gVCF) (+ .tbi). bcftools, samtools, tabix; depending on options and inputs, also: delly, pbsv, sambamba, sniffles; hours on a 30x genome wgsextract vcf call --input sample.cram --types snp,indel --merge
vcf annotate Add external metadata (like population frequencies or disease risk) to your VCF file. annotated.vcf.gz (+ .tbi). bcftools, tabix; depending on options and inputs, also: bgzip, samtools; minutes on a 30x genome wgsextract vcf annotate --vcf-input sample.vcf.gz --ann-vcf dbsnp.vcf.gz --cols ID
vcf filter Filter your results. filtered.vcf.gz (+ .tbi). bcftools, tabix; depending on options and inputs, also: bgzip, samtools; minutes on a 30x genome wgsextract vcf filter --vcf-input sample.vcf.gz --genes BRCA1,BRCA2 --bed targets.bed
vcf table Export variants and their annotations (gene, consequence, ClinVar, gnomAD, genotype, depth, ...) as one row per variant, in a TSV (or Parquet) table and an SQLite database to query. <input stem>_variants.tsv (or .parquet with --format parquet) and <input stem>_variants.sqlite: one row per variant allele, with its annotations. bcftools; depending on options and inputs, also: bgzip, tabix; minutes on a 30x genome wgsextract vcf table --vcf-input sample.vcf.gz --bed targets.bed
vcf prepare Repair a VCF from a sequencing service so other tools accept it: BGZF compression, sorting, contig names and header lines, and a fresh index; optionally split multiallelics and left-align indels. <input stem>_prepared.vcf.gz (+ .tbi, or .csi for contigs over 512 Mb). bcftools, tabix; minutes on a 30x genome wgsextract vcf prepare --vcf-input sample.vcf.gz
vcf compare Compare normalized small alleles across local callsets. compare.summary.json and compare.summary.tsv (or .parquet); optional compare.variants table and indexed compare.anchor.vcf.gz. bcftools; depending on options and inputs, also: samtools, tabix; minutes on a 30x genome wgsextract vcf compare --callset a=caller-a.vcf.gz --callset b=caller-b.vcf.gz --ref GRCh38.fa
vcf clinvar Annotate VCF with ClinVar pathogenicity data. clinvar_annotated.vcf.gz and clinvar_pathogenic.vcf.gz (+ .tbi). bcftools, tabix; depending on options and inputs, also: bgzip, samtools; minutes on a 30x genome wgsextract vcf clinvar --vcf-input sample.vcf.gz
vcf revel Annotate VCF with REVEL pathogenicity scores. revel_annotated.vcf.gz (+ .tbi); with --min-score N, also revel_gt_N.vcf.gz. bcftools, tabix; depending on options and inputs, also: bgzip, samtools; minutes on a 30x genome wgsextract vcf revel --vcf-input sample.vcf.gz
vcf gnomad Annotate VCF with gnomAD population frequencies. gnomad_annotated.vcf.gz (+ .tbi); with --max-af AF, also gnomad_af_lt_AF.vcf.gz and its .confidence.tsv table. bcftools, tabix; depending on options and inputs, also: bgzip, samtools; minutes on a 30x genome wgsextract vcf gnomad --vcf-input sample.vcf.gz --max-af 0.01
vcf sv-freq Annotate SVs with gnomAD-SV/gnomAD-LR frequencies. sv_freq_annotated.vcf.gz (+ .tbi) and sv_freq.tsv. bcftools, bgzip, tabix; depending on options and inputs, also: samtools; minutes on a 30x genome wgsextract vcf sv-freq --vcf-input sniffles.vcf.gz
vcf pharmgkb Annotate VCF with PharmGKB drug metabolism data. pharmgkb_annotated.vcf.gz (+ .tbi) bcftools, tabix; depending on options and inputs, also: bgzip, samtools; minutes on a 30x genome wgsextract vcf pharmgkb --vcf-input sample.vcf.gz
vcf info Quick summary of a VCF, gVCF or BCF: reference build/model, samples, format, and record counts. Prints a VCF summary (reference model/build, samples, format, record counts); writes no files unless --card is set. bcftools; depending on options and inputs, also: htsfile, samtools, tabix; seconds on a 30x genome wgsextract vcf info --vcf-input sample.vcf.gz
vcf variantqc Run DISCVRSeq VariantQC to generate an interactive HTML VCF quality report. <stem>.variantqc.html interactive VariantQC report from DISCVRSeq. no external tools; depending on options and inputs, also: bcftools, discvrseq, java17, samtools; minutes on a 30x genome wgsextract vcf variantqc --vcf-input sample.vcf.gz
vcf granite-qc Run granite qcVCF (dbmi-bgm/granite) for single-sample or family VCF quality metrics. <stem>.granite_qc.json quality metrics report from granite qcVCF. bcftools; depending on options and inputs, also: granite, samtools; minutes on a 30x genome wgsextract vcf granite-qc --vcf-input sample.vcf.gz
vep download Build vep-rs's VEP cache from Ensembl's files (GRCh37/38, T2T-CHM13v2.0), or download Ensembl VEP's with --engine ensembl, for offline annotation. Into the VEP cache directory (vep_cache, or --vep-cache). samtools, vep-cache-builder; depending on options and inputs, also: curl, tar; depends on download speed wgsextract vep download --assembly GRCh38
vep verify Check your existing VEP cache for missing files or corruption. Prints what is missing or damaged; writes no files. no external tools; seconds wgsextract vep verify --assembly GRCh38
vep delete Delete one release and assembly of your VEP cache. Deletes <cache>/<species>/<release>_<assembly>; writes no files. no external tools; seconds wgsextract vep delete --assembly GRCh38
vep run Variant Effect Predictor, with vep-rs (default) or Ensembl VEP (--engine ensembl). <input stem>_vep.vcf.gz (or .tsv/.json with --format), with VEP's summary. bcftools, tabix, vep-rs; depending on options and inputs, also: samtools, vep; minutes on a 30x genome wgsextract vep run --input sample.vcf.gz
report Summarise a sample's results in one local HTML report. <sample>_personal_report.html, .md and .json and <sample>_personal_report_findings.tsv (or .parquet with --format parquet) in the sample folder (or --outdir); evidence links are relative to the sample folder. no external tools; depending on options and inputs, also: curl; seconds from existing results wgsextract report --genome HG002

ref index Prepare a FASTA file for use by indexing it. Beside the FASTA: .fai, .dict and the aligner's index files. samtools; depending on options and inputs, also: bwa, bwa-mem2, curl; hours, once per reference wgsextract ref index --ref hs38.fa

Beside the FASTA: <FASTA>.wgse-sa16, wgse-bwa's optional dense suffix-array file (0.8 GB for hs38); --list prints the FASTA's files, --delete removes them. no external tools; minutes, once per reference wgsextract ref dense-sa --ref hs38.fa
ref count-ns Calculate the percentage of 'N' (unknown) bases in a genome. <reference stem>_ncnt.csv and <reference stem>_nbin.csv. no external tools; minutes, once per reference wgsextract ref count-ns --ref hs38.fa
ref verify Ensure your reference genome file isn't corrupted and has all the necessary companion files (indexes, dicts). Prints what is missing or damaged; creates a missing .fai (and .gzi for a compressed FASTA) beside the FASTA. samtools; minutes, once per reference wgsextract ref verify --ref hs38.fa
ref library Opens the interactive reference manager to help you organize and download genomic data. Into the reference library (reflib): the chosen reference genome and its indexes. bcftools, bgzip, curl, htsfile, samtools, tabix; depends on download speed wgsextract ref library --list
ref status Report reference library asset status. Prints the reference library's status; writes no files. no external tools; seconds wgsextract ref status
ref recheck Compare the resource releases result manifests recorded with the newest: from --answers FILE, or ask NCBI with --online. Prints each recorded resource release, the newest and its status; writes no files except the --save-answers file. With --json, the result's details are the wgsextract.recheck/1 document. no external tools; seconds wgsextract ref recheck HG002/HG002_personal_report.manifest.json --answers answers.json
ref test-genome Report, install (--install) or delete (--delete) the small hg19 test genome in the dataset library. In the dataset library: wgsextract-benchmark-hg19-mini/ with its genome-config.toml, and the verified zip in .downloads (--delete removes both). Without --install or --delete, prints its status. no external tools; depending on options and inputs, also: curl; depends on download speed wgsextract ref test-genome --install
ref needs Report the reference genome, annotation data or optional tools a command line needs that aren't installed, and how to install them. Prints the missing reference genome, annotation data or optional tool and the command that installs each; writes no files. With --json, the result's details.missing lists them. no external tools; depending on options and inputs, also: bcftools, tabix; seconds wgsextract ref needs -- info --input sample.cram
ref gene-map Download or delete lightweight gene-to-coordinate mapping files (hg19/hg38), enabling you to filter VCFs by gene name (e.g. BRCA1), with the RefSeq transcript and exon models the genome viewer and info gene show. Into the reference library (reflib): the hg19 and hg38 gene maps and their indexed RefSeq transcript and exon models, transcripts_<build>.bed.gz, for the genome viewer and info gene (--delete removes them). no external tools; depending on options and inputs, also: bgzip, curl, tabix; depends on download speed wgsextract ref gene-map

deps ready Report whether a command line can run on this computer without the network: its tools, images, GPUs, model weights, input, reference genome and indexes, checked offline without installing or downloading anything.
